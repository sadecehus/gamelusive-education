# 🎮 Game'Lusive Education

Erasmus+ **Game'Lusive Education** projesi için geliştirilen çok dilli eğitim web sitesi. Eğitici mini oyunları ve proje içeriğini 5 dilde sunar.

🔗 Canlı: [www.gamelusiveedu.eu](https://www.gamelusiveedu.eu)

## 🌍 Desteklenen Diller

İngilizce (varsayılan) · Lehçe · Türkçe · Felemenkçe · Litvanca

## 🕹️ İçerik

Solar System, Eco Guardian, CodeCraft, Weather Wizard, Color the Verb, Daily Routines Puzzle, Sound Match, Journey to School ve daha fazlası — `public/games/` altında.

## 🚀 Çalıştırma

```bash
npm install
npm run dev
```

Statik dışa aktarım:

```bash
npm run build
```

## 🛠️ Teknolojiler

Next.js · TypeScript · Tailwind CSS · Radix UI / shadcn/ui · Framer Motion
